# Y（架空SNS）— オープンキャンパス体験授業用デモ

オープンキャンパスに来校した高校生（PC・プログラミング未経験者が中心）向けの体験授業「ブラウザの検証機能を使ったWeb画面の書き換え体験（通称：なんちゃってハッキング）」のために作った、**実在のX（旧Twitter）そっくりの見た目をした架空SNS**です。実在サービス・実在企業とは無関係の、教育目的のフロントエンドのみのデモです。

公開URL: **https://kodak37.github.io/x_demo/**

---

## この授業で伝えたいこと

「表示されている画面は、ブラウザ側で自由に書き換えられる（＝画面の見た目を信用しすぎてはいけない）」ということを、実際に手を動かして体感してもらう。実在のXではなく本サイトを使うことで、実サイトの回線トラブルや複雑なUIに左右されず、`右クリック → 検証 → 数文字打ち替え` だけで完結させる。

## なぜ動くのか（技術的な仕組み）

- サーバーは存在しない、ログイン機能もない、純粋な HTML / CSS / JavaScript のみの静的サイト
- 「投稿する」「いいね」「プロフィール編集」などは全部その場限りの見た目上の変化（ブラウザのメモリ上でDOMを書き換えているだけ）
- **ページを再読み込み（F5）すると必ず初期状態に戻る** → これが種明かしパートの核心（「サーバーに保存されていない＝あなたの画面の中だけの出来事だった」）

## 体験授業の3ミッション

DevToolsの開き方: 画面上で**右クリック → 「検証」**（Windows/Mac共通、Chrome・Edgeで動作確認済み）。ショートカットは Windows は `F12` または `Ctrl+Shift+I`、Mac は `Cmd+Option+I`。

| # | ミッション | 具体的な操作 | 対象要素の例 |
|---|---|---|---|
| 1 | 名前・プロフィールの書き換え | 該当テキストをダブルクリックして直接編集 | プロフィール画面の名前「山田 太郎」、自己紹介文、投稿本文 |
| 2 | 数値のインフレ化 | 数字部分をダブルクリックして書き換え | フォロワー数「312」、投稿の所持金「1,200円」、いいね数など |
| 3 | アイコン画像の差し替え | `<img>` タグの `src` 属性の値を書き換え | プロフィールアイコンの `src` を `images/avatar-default.svg` → `images/avatar-gorilla.svg` に変更 |

いずれも保存ボタンは無く、書き換えた瞬間に画面へ反映される。**F5でリロードすれば全部元通り**になることを、種明かしのタイミングで実演する。

## 画面構成（何が本物っぽく動いて、何が飾りか）

| 画面 | 内容 | 備考 |
|---|---|---|
| ホーム | みんなの投稿が流れるタイムライン | いいね・リポスト・返信・新規投稿は実際に反映される（保存はされない） |
| プロフィール | 自分のページ（アイコン・自己紹介・フォロワー数など） | 「プロフィールを編集」から名前・自己紹介・アイコンファイル名を変更可能 |
| 話題を検索 | トレンド一覧・おすすめユーザー | **検索ボックスは見た目のみで実際には検索できない**（授業の要件通り） |
| 通知 | いいね・リポスト・フォロー等の通知一覧 | 見た目のみ、開くとバッジが消える |
| 投稿フォーム（モーダル） | 「ポストする」から開く | 文字数カウンター・画像/絵文字アイコン等も見た目として実装済み |

## 当日までの準備（アイコン画像の差し替え）

`images/avatar-gorilla.svg` と `images/avatar-sensei.svg` は現状プレースホルダー（絵文字ベースの仮画像）です。実際のゴリラ・先生の写真を用意できる場合は、**同じファイル名のまま中身だけ差し替えて** GitHub にpushしてください。`index.html` 側の変更は不要です。

```
images/avatar-gorilla.svg   ← ここを実際のゴリラ画像に差し替え
images/avatar-sensei.svg    ← ここを実際の先生の画像に差し替え
```

## ファイル構成

```
index.html   ページ本体（ホーム／プロフィール／検索／通知／各種フォームのHTML）
style.css    スタイル（Xのダークモード配色・レイアウトを再現）
script.js    画面切り替え・投稿・いいね等の挙動（すべてクライアント側のみで完結）
images/      アイコン・アバター・カバー画像など
robots.txt   検索エンジンにインデックスさせないための設定（デモサイトのため）
```
