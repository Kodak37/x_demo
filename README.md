# Y（架空SNS）— オープンキャンパス体験授業用デモ

高校生向けオープンキャンパスの体験授業「ブラウザの検証機能を使ったWeb画面の書き換え体験（なんちゃってハッキング）」で使う、**実在のX（旧Twitter）を模した架空のSNS**です。実在サービスとは一切関係ない、教育目的のローカル完結型デモです。

サーバー通信やログインは一切なく、すべての操作（投稿・いいね・プロフィール編集など）はブラウザ内だけで完結します。**ページを再読み込み（F5）すると必ず初期状態に戻ります**。この仕組み自体が、種明かしパート（「なぜ戻るのか＝ブラウザとサーバーの違い」）の教材になっています。

## 公開URL

GitHub Pagesで公開しています：<https://kodak37.github.io/x_demo/>

## 体験授業のミッション対応

1. **名前・プロフィールの書き換え** — `検証` → 名前やプロフィール文をダブルクリックして書き換え
2. **数値のインフレ化** — フォロワー数・いいね数・所持金などの数字を書き換え
3. **アイコン画像の差し替え** — `<img>`タグの`src`属性を`images/`内の別ファイル名に書き換え（ゴリラ・先生の画像に変更）

## アイコン画像の差し替え（当日までの準備）

`images/avatar-gorilla.svg` と `images/avatar-sensei.svg` は現在プレースホルダーです。実際の写真を使いたい場合は、同じファイル名のまま中身を差し替えてください（コード側の変更は不要です）。

## ファイル構成

```
index.html   ページ本体（タイムライン／プロフィール／検索／通知／各種フォーム）
style.css    スタイル（Xのダークモード配色を再現）
script.js    画面切り替え・投稿・いいね等の挙動（すべてクライアント側のみ）
images/      アイコン・カバー画像など
robots.txt   検索エンジンにインデックスさせないための設定
```
